# 🚀 Kaushalam Platform

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![PRs Welcome](https://img.shields.io/badge/PRs-welcome-brightgreen.svg)](CONTRIBUTING.md)

**Kaushalam Platform** is an open platform designed to bridge skill gaps, enable personalized learning paths, and connect skilled individuals with relevant career or project opportunities.

---

## 📌 Features

- 🎯 **Skill Assessment & Mapping:** Interactive skill evaluation and progress tracking.
- 📚 **Personalized Learning Routes:** Recommended courses, modules, or tracks based on user goals.
- 💼 **Opportunity Matching:** Connect users directly with relevant projects, jobs, or mentorship.
- 📊 **Analytics Dashboard:** Insights into skill growth, completion rates, and performance metrics.
- 👥 **Community & Collaboration:** Forums and group discussions for peer-to-peer learning.

---

## 🛠️ Tech Stack

- **Frontend:** React / Vite
- **Backend:** Node.js / Express
- **Database:** SQLite
- **Authentication:** JWT
- **Deployment:** Render

## 🚀 Getting Started

Follow these instructions to get a local copy of the project up and running.

### Prerequisites

Ensure you have the following installed on your machine:

- [Node.js](https://nodejs.org/) (v18 or higher)
- [Git](https://git-scm.com/)
- Database service (e.g., SQLite)

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Pradhyumn-24/kaushalam-platform.git
   cd kaushalam-platform
   ```

2. **Install dependencies:**

   ```bash
   npm install --Force
   ```

3. **Set up Environment Variables:**

   Create a `.env` file in the root/backend directory by copying `.env.example`:
   ```bash
   cp .env.example .env
   ```
   Fill in your configuration details (Database URL, Secret Keys, Port, etc.).

4. **Run the Application:**

   Start the backend server:
   ```bash
   npm run dev
   ```

   Start the frontend client:
   ```bash
   npm start
   ```
